Processing setup

Choose one path. Local mode processes audio on your computer; API mode sends it to Deepgram.

Community-1 · Kaggle GPU

Tải notebook Kaggle

Bật GPU, Internet và Secret HF_TOKEN trong notebook Kaggle. Giữ server local chạy; không chia sẻ notebook chứa khóa phiên.

Local · No account required

Run setup.ps1 -LocalModels once to install the libraries and download English Whisper and speaker recognition models. After setup, recordings are processed on this computer without sending audio elsewhere.

No API key or Hugging Face token is needed. CPU processing can take longer than the recording itself.

API · Deepgram

Set DEEPGRAM_API_KEY in meeting-ai/.env and restart. This may incur provider usage charges. The key stays on the backend.

Summary · Local or API

For local drafts, start Ollama and run ollama pull qwen2.5:3b. Set OLLAMA_MODEL=qwen2.5:3b in .env. CPU generation can take several minutes. API mode uses LLM_API_URL, LLM_API_KEY, and LLM_API_MODEL; selecting it sends transcript text to that provider.

Chế độ Kaggle GPU dùng worker đang kết nối để nhận diện, tóm tắt và hỏi đáp. Không cần bật Ollama khi chọn GPU. Lần đầu tải model có thể lâu hơn.

Local status checks installed libraries and downloaded files. API status checks only whether a key is configured. Full instructions are in meeting-ai/README.md.
